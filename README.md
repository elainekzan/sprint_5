# Projeto Sprint 5 — Análise de anúncios de veículos

Este projeto desenvolve um aplicativo web utilizando Streamlit para explorar e visualizar dados de anúncios de vendas de veículos nos Estados Unidos.

## Funcionalidades

O aplicativo permite:

- Visualizar informações dos anúncios de veículos.
- Criar um histograma para analisar a quilometragem dos veículos.
- Criar um gráfico de dispersão relacionando a quilometragem e o preço dos veículos.
- Interagir com os gráficos de forma dinâmica.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit

## Dataset

O aplicativo utiliza o arquivo `vehicles_us.csv`, contendo dados de anúncios de vendas de veículos.
